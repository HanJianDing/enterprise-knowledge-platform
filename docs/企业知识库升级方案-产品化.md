# 企业知识库升级方案：从"能用的系统"到"拿得出手的产品"

> 定位：这不是 demo，是真正能落地的企业项目。三个目标——
> 1. **华丽**：打开页面第一眼就要"哇"（深色模式、工作台看板、引用直达原文）
> 2. **炫技**：踩 2026 最热技术点（MCP、Agentic RAG、评估体系），且有真实需求背书，经得起面试追问
> 3. **可信**：企业级缺的功课（备份、密码策略、审计导出、监控告警）补齐，被问运维问题不露怯

## 一、面试视角的验收标准

| 看什么 | 场景 | 内容 |
|---|---|---|
| 一眼（10 秒） | 打开页面 | 深色/浅色主题、工作台数据看板、聊天页引用三件套、解析流水弹窗 |
| 二眼（2 分钟） | 点几个页面 | 知识库权限页、审计页、试检索/评估跑分页、MCP 配置页 |
| 三眼（20 分钟） | 深聊 | Agentic RAG 设计取舍、MCP 权限穿透与审计、检索生成解耦、测试基线 |

三眼是防线：前两眼吸引人，第三眼让面试官追问不下去——每个功能都有"为什么这么设计"的真实答案。

## 三、阶段 A：基本功（产品面）

### A1 分块模板化（后端，借鉴 RAGFlow）
现在统一切分，表格类文档被切得稀碎。新增按文件类型自动选模板：
- **table 模板**：Excel/CSV/PDF 表格按行列结构切，表头自动注入上下文——"请假三天扣多少"这类问题能答对
- **qa 模板**：问答对语料按问题切，保留问题当上下文——《常见问题手册》
- **laws 模板**：制度按"第X条/款"编号层级切——《考勤管理制度》类
- **通用切分升级**：层级合并（hierarchical merge）+ overlap 策略照搬

**验收**：上传含表格的《考勤制度》→ 问"请假三天扣多少"答对；60 题评估集分数不降。

### A2 引用溯源三件套（前端 + 后端）
企业知识库的命根子是"答案可查证"，现在只有来源列表，升级为三件套：
1. 答案下方**引用卡片组**：文件名 + 相关度 + 片段预览
2. 点击引用 → **侧边抽屉打开原文，定位到该切片并高亮**（后端需返回 chunk 位置元数据）
3. 正文 [N] 标记可点击，悬浮显示对应切片

**验收**：答案里每个引用都能一键跳到原文对应位置，高亮显示。

### A3 上传解析状态可视化（前端 + 后端）
- **彩色状态徽章**：成功绿 / 失败红 / 运行蓝 / 排队黄
- **解析事件流水弹窗**：点开文档看"开始解析 → 耗时 → 切了几块 → 花了多少 token → 错误详情"完整过程（job 表加事件流水字段）

**验收**：故意传一个坏文件，能在流水里看到具体错误原因，而不是干巴巴的"失败"。

### A4 前端华丽化（重点，解决"半成品感"）
- **深色模式**：AntD6 暗色算法 + 语义 token，localStorage 记忆，全站无破绽
- **首页工作台**（登录后第一屏）：统计卡片（用户数/知识库数/文档数/今日问答数）+ 热门问题 TOP10 + 问答趋势图（echarts，已有依赖）+ 最近审计动态
- **登录页视觉升级**：渐变/动画背景（借鉴 RAGFlow 发光路径 SVG）
- 全局统一视觉规范：间距、圆角、图标、空状态插画

**验收**：深浅主题切换全站无破绽；工作台数据全部真实可点（不是假数据）。

### A5 文档预览补全
至少补 xlsx/csv 预览——点击 Excel 类文档的引用能直接看表格内容。

## 四、阶段 B：炫技包（技术面）

### B1 Agentic RAG：复杂问题检索编排（借鉴 RAGFlow Deep Search 思路，自研轻量版）
普通 RAG 一锤子买卖，答不了"对比 2024 和 2025 差旅标准""我年假还剩几天"这类问题。方案：
- **复杂度检测**：提示词判定问题类型（比较类/计算类/多文档类 → 走编排；普通问题 → 直答，不增加延迟）
- **编排循环**：拆子问题 → 多路检索 → 各自生成 → 汇总，最多 3 轮防失控
- **计算类**：提取数值后**用程序计算**，不靠大模型算数（大模型算数不可靠，这是面试必聊点）
- **全程带引用**：子问题的来源也汇总进最终引用

**验收**：问"对比两年差旅标准"得到分点对比 + 双来源引用；普通问题延迟不受影响；评估集分数不降。

### B2 MCP Server：把检索能力标准化（杀手锏：权限穿透）
用 FastMCP 在现有 FastAPI 加 `/mcp` 端点（薄壳方案，不拆服务）：
- 工具：`search_kb(question)`、`list_visible_kbs()`、`clarify(question)`
- **权限穿透**：工具调用按调用者身份走现有部门-KB 权限（fail-closed）——市面上大部分 MCP 集成不管权限，这是差异化
- **审计埋点**：每次工具调用写审计日志（复用现有体系）
- **返回结构"自带质量"**：片段 + 来源 + 相关度 + 拼好的引用指令文本（生成侧兜底下沉到检索层）

**验收**：用 Claude Desktop 连上实测——普通用户只能检索到自己可见的库，越权调用被拒，审计页有调用记录。

### B3 MCP Client：外接应用的工具调用循环
给聊天流程加工具调用步骤（qwen-plus function calling）：
- 内置演示工具：计算器、日期查询（走真实 MCP server）
- 预留 OA 对接配置位（公司有 OA 就填，没有就演示模拟 server）
- 演示场景："我的报销单到哪一步了" = 制度检索 + OA 实时数据合成回答

**验收**：工具调用全链路有审计；模拟 OA server 能合成"制度+实时数据"回答。

### B4 评估体系可视化（面试现场武器）
- **试检索页**（管理端）：输入问题立刻看命中片段 + 相关度，调参即时反馈
- **评估跑分页**：60 题一键跑，展示检索/回答质量指标（对接现有评估脚本）

**验收**：面试演示时当场跑评估出指标——比口头说"效果 91.67%"有说服力十倍。

## 六、阶段 D：可选升级（换硬件后）

| 项 | 说明 | 前提 |
|---|---|---|
| pgvector 换 Chroma | 数据库内混合检索，运维不变（已有 PG） | 8C16G 或分块量上来后 |
| 本地 embedding/rerank | bge-m3 + bge-reranker 本地部署，数据不出内网 | 复用已有 LLM_API_BASE 插槽，改配置即可 |
| 扫描件 OCR | DeepDoc ONNX，CPU 可跑；做成"上传时勾选扫描件"开关 | 有扫描件需求时 |
| 企业术语同义词 | "OA/差标/HR"等查询侧自动扩展 | 随时可做，成本低 |
| 企微/钉钉机器人通道 | IM 内直接问答，内部知识库杀手功能 | 有企业账号时，复用 SSO 插槽凭据 |
| 本地 LLM | vLLM + Qwen，彻底数据不出内网 | 有 GPU 时 |

## 七、不做清单（每个都有想清楚的理由，面试被问"为什么没做"有答案）

| 不做的 | 理由 |
|---|---|
| Agent Canvas 画布 / MCP 沙箱 | 500 员工不会搭应用；为 2 个管理员维护可视化编程平台不划算 |
| RAPTOR | RAGFlow 自己都删了，收益被摘要类方案覆盖 |
| 多语言 i18n | 内部系统中文单一语言 |
| 多模型对比 | 开源社区炫技功能，企业内部用不上 |
| ES 全套基础设施 | 4C4G 装不下；pgvector 是更优解 |

## 八、质量与交付纪律（每个阶段不变）

- 每阶段：后端 pytest 全绿（现 244）+ 前端 vitest 全绿（现 65）+ 迁移链验证
- 每阶段结束：gitcommit-agent 双通行证（测试员 + 质量工程师）提交
- 每阶段给你验收清单：打开哪个页面 → 点什么 → 应该看到什么
- 阶段间不留半成品；评估集每阶段跑一遍确认检索质量不降
