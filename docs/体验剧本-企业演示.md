# 体验剧本：企业知识库演示（种子数据版）

> 演示环境与真实环境完全隔离（ragdb_demo 数据库 + chroma_demo 向量库）。
> 启动后端：项目根目录 `python run_demo.py`（端口 8010）。
> 启动前端（指向演示后端）：frontend 目录 `VITE_BACKEND_URL=http://localhost:8010 npm run dev`。
> 账号：admin/CHANGE_ME_DEMO_PASSWORD（管理员）、hr01、fin01、adm01、it01、mkt01、rd01（六部门员工，密码 CHANGE_ME_DEMO_PASSWORD，it01 首登强制改密）、auditor01（审计员）。

## 场景 0：登录与首登改密

1. 用 `it01 / CHANGE_ME_DEMO_PASSWORD` 登录 → 被强制跳转"修改密码"页 → 改完重新登录（演示首登强制改密）
2. 用 `admin / CHANGE_ME_DEMO_PASSWORD` 登录 → 进入工作台：问候语、统计卡片、近 7 天趋势、推荐问题

## 场景 1：权限隔离（核心卖点）

1. 用 `hr01` 登录 → 工作台统计只显示"可见文档"（约 60 篇：人事库约 40 + 公共库约 20）
2. 问"市内交通费每天能报销多少" → 答"暂无相关信息"——这是财务库《费用报销制度》第七条的内容，hr01 看不到（干净利落的隔离演示）
3. 问"报销标准是多少" → 命中人事库《考勤管理制度》第五章"加班餐费报销标准 30 元"（分块修复后稳定命中），**财务库的交通/差旅/招待标准一条不漏**，回答还会主动说明"其他类型未提及"（fail-closed 的生动演示）
4. 问"婚假几天" → 命中《年假管理制度》，答案带 [来源1] 引用
5. 点击"来源1"标签 → 抽屉展示切片原文 + 上下相邻切片 + "第 N/M 块"定位
6. 用 `admin` 登录 → 问"市内交通费每天能报销多少" → 命中财务库《费用报销制度》第七条（100 元/天），与 hr01 的"暂无"形成对照（admin 全库可见）
7. **敏感数据分级可见（验收批次1·8j 升级：三层叙事）**：hr01 问"2025年营业收入是多少" → 答"暂无"（《2025年度经营分析报告》在经营管理库，员工按部门权限不可见）；用 `fin01` 问同一问题 → 命中（财务部获部门授权）；用 `mgmt01 / CHANGE_ME_DEMO_PASSWORD`（管理层账号）问 → 命中年报——"管理员管系统、管理层看经营数据、员工按部门"三层权限叙事（经营管理库授权：mgmt01 个人读+传+管、财务部部门读）

## 场景 2：复杂问题编排（B1）

用 admin 问：
1. "对比2024和2025的差旅标准" → 界面显示"正在拆解子问题 → 检索子问题 1/2 → 汇总"，得到分点对比（2024 版住宿 400 元/晚、2025 版上调至 450 元/晚，双来源引用）
2. "我今年有10天年假，已经休了3天，还剩几天？" → 显示"正在调用工具：calculator"，答案含程序计算结果
3. "今天星期几" → 工具调用 datetime

## 场景 3：上传体验（你手动上传的部分）

1. admin → 知识库管理 → 选择对应知识库（报销流程速查 → 财务制度库，考勤表 → 人事制度库）
2. 上传 `D:\文档数据\体验上传\` 里的文件（共 11 个，各归其库）：
   - 考勤打卡记录.csv → 内容类型选"表格数据"，父分类"考勤"、子分类"表单"
   - 报销流程速查.docx → "长文本"，父分类"报销"、子分类"流程"
   - 新员工入职准备清单.md → "长文本"
3. 上传"损坏的扫描件.pdf" → 状态变红"失败" → 点"流水"看时间轴中文错误详情（A3 演示）
4. 对已完成文档点"重切" → 确认弹窗 → 按新模板重新分块
5. 上传完成后观察：状态自动刷新（轮询），不用切页面

## 场景 4：分块模板效果（A1）

1. 知识库管理 → 查看《差旅费用标准.xlsx》的"分块" → 每块带"【表格：差旅标准】列：…"表头上下文
2. 问"杭州出差住宿标准多少钱" → 命中表格切片
3. 查看《考勤管理制度.txt》的分块 → 条款模板：每块带"【第三章 迟到与早退 → 第五条】"路径

## 场景 5：评估可视化（B4）

4. 用户管理 → 重置一个员工密码（试试弱密码被拦）→ 该员工登录被强制改密

## 场景 7：MCP 接入（B2）

1. 登录接口拿 access_token（浏览器 F12 Network 或 curl）
2. Claude Desktop 配置 `mcpServers`：url `http://localhost:8010/mcp/` + Bearer token
3. 在 Claude Desktop 调 `list_visible_kbs` / `search_kb` → 结果带 [来源N] 引用
4. 用 hr01 的 token 调 search_kb 问财务问题 → 返回"未找到"（权限穿透演示）

## 场景 8：运维（C 批次）

1. `python scripts/health_check.py --url http://localhost:8010` → 健康检查通过
2. `python scripts/backup.py --backup-dir D:/backups_demo --keep 3` → 生成备份并验证目录结构
3. 审计保留策略：`python scripts/purge_audit_logs.py --keep-days 90`（演示环境跑一次即可）
